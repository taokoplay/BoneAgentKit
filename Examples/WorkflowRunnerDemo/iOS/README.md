# Agent Lab · iPhone Demo

原生 SwiftUI 测试 App，最低 iOS 26.0，当前版本为 1.0 build 19。主入口只有“对话”和“实验室”，共用模型、助手说明和工具；搜索模块统一管理手动网页、百度网页问答、Brave 和 DeepSeek 搜索。合成场景保留在 [命令行 Demo](../README.md) 与自动回归中。

## 在手机上测试

打开 **Agent Lab**：

1. 在“对话”或“实验室”右上角打开“设置”。“模型连接”默认只需选择服务商、模型和填写 API Key；自定义接口、回复参数、上下文及图片能力折叠为可选设置。
2. 服务商、模型和图标读取 SDK 目录。可刷新账号可见模型，也可手动填写模型 ID；刷新不会自动替换已有选择。“助手说明”只有一份，对话与模型测试都会使用。
   智谱 AI 和智谱 Coding Plan 不预选 GLM 模型。填入对应渠道的 Key 后，打开“从账号模型列表选择”会请求上游；没有 Key 或加载失败时仍可手动填写模型 ID。
   OpenAI 与 Anthropic 兼容格式填写 HTTPS 接口地址后，打开列表会查询上游且不预选；无需鉴权的网关可不填 Key 查询。网关未提供列表时仍可手填模型 ID。
3. 进入“实验室”，在“任务类型”选择“普通任务”或一个测试。填写任务；需要工具时展开“工具”，逐项勾选或使用预设。选择暂存，点击运行时应用。替换已有任务文字需要确认，示例不会自动发送。
4. 普通任务的回答显示在“对话”；测试使用独立 Conversation，完成后进入“测试结果”，保留原有聊天和待发附件。测试不自动上传这些附件。结果按实际检查显示“检查通过”“检查未通过”或“已完成，待你检查”。
5. 发送或测试进行中可停止；不会自动重试或回退演示回复。运行时锁定配置，不能同时发送对话和测试。设置保存后保留任务与工具选择，下一次请求才使用新配置；旧对话如需重开，会先确认并保留待发材料。
6. 默认使用流式回复和上下文整理。右上角图表可查看 SDK 状态、用量和时间；未上报的值保持“未提供”。可选摘要、会话保存、图片输入均在模型连接的折叠设置中。
7. 普通任务可“添加文本材料”，也可在对话加号导入 UTF-8 文本；每份文件最多 100 MiB，每个对话最多 4 份；超过 512 KiB 需关闭会话保存，粘贴文本仍限 512 KiB。点附件名称可在本机分页预览，每页至多 16 KiB，使用 SDK 的 UTF-8 `nextOffset` 前后翻页，不调用模型或网络。模型先收到至多 1 KiB 预览，再按需列表、检索及分页读取；当前 Conversation 的工具只可访问明确发送过的精确文件版本。导入在本机完成，点击运行后才发送。
8. 图片理解默认关闭，需先保存与精确模型和接口绑定的规则，再从对话加号选图。支持明确列出的 GPT-4.1 mini 规则或用户配置的正值 Host 预算；配置预算不代表模型一定支持图片。

图片先由 SDK ImageIO 在本机归一化方向并去除位置等源元数据，最长边 1024、每张处理后最多 2 MiB、每对话最多 6 张。源图最大 20 MiB / 1600 万像素。预览可移除；已发送的附件保留供对话历史解析。选择和预处理不会上传，点击发送后才进入当前服务商请求。

对话发送后保留键盘，可继续写下一条草稿；点右上角“收起键盘”可关闭。异常提示可“取回原问题”；“开始新对话”会先保留原问题、输入草稿和未发送材料。输入框已有内容时，原问题放入“保留的任务”，两个位置均有其他内容时阻止重置以免覆盖。左上角“新对话”仍会先确认清空消息、草稿和材料。测试的停止、失败或重新运行均不清空普通对话。

失败任务按“问题文字 + 附件引用”一起保留，包括此前成功轮次已经发送、后续问题仍可能需要的文件。“重试原任务”使用原文件版本，并保留输入框中的下一条问题及其附件；仅带附件的草稿同样视为占用。取回原问题时，不会把两条任务的文件合并。上述恢复信息只在本次进程中保留，不额外持久化用户文件。

重试保留任务释放槽位时，另一条失败任务及其材料会转入该槽位。用户问题仍以 16 KiB 为限；最多四份附件的预览、文件名与引用使用独立的 40 KiB JSON 封装预算，避免恢复旧附件压缩原问题的合法长度。SDK 的累计输入和执行预算继续生效。

聊天 Demo 的 `resource.readText` 默认使用 `resourceID` 与从 0 开始的 `page`（省略为 0）。从搜索结果扩读时，也可直接复制命中提供的 `offset`。附件预览附完整 `firstRead` 参数；每页返回完整 `nextRead`，末页为 `null`。App 绑定当前会话获准的文件版本，并按 UTF-8 边界每页返回至多 16 KiB；模型不需要自行计算偏移。列表和检索只覆盖当前已发送文件。独立文本实验与 SDK 的通用字节读取接口保持不变。

读取参数失败显示“资料读取参数有误”，并区分缺少字段、字段类型、页码越界、请求末页之后、引用不匹配及无权访问等固定诊断码，不记录参数值或正文。失败不会自动重试或改用其他文件；可本机预览附件或显式重试原任务。提高回复 Token 上限仅影响模型输出，不能修正工具参数。

新选择的 DeepSeek 会采用 SDK 当前的 Anthropic 默认接口和模型。旧版已保存的 DeepSeek OpenAI 兼容连接保留原协议、地址、模型和凭据范围；重新选择服务商时才应用当前 SDK 默认值。OpenAI 与 Anthropic 兼容格式可从匹配的完整聊天 URL 推导列表地址；其他渠道在完整聊天 URL 模式仅显示内置模型。

服务商与模型行显示 SDK 的渠道 PNG，模型图标表示当前服务商，不是独立的模型品牌图标。资源直接从 SDK bundle 读取，未复制到 Demo；适用仓库 [NOTICE](../../../NOTICE.md) 的渠道图片说明。

## 可选内置工具

功能由独立的 `BoneAgentTools` 产品提供，SDK 默认不注册任何工具。完整开发接入见 [可选内置工具文档](../../../Documentation/BuiltInTools.md)。

Agent Lab 当前接入五类 Apple 系统工具。日历、提醒事项、联系人支持有界查询和确认后的写入，本地通知只管理本 App 自己安排的通知，相册只保存当前 Host 已登记的图片。系统权限由 iOS Host 请求，SDK 只提供跨平台契约和工具定义。

Apple Notes、系统通知中心历史、Mail 收件箱和 Messages 历史没有适合通用 SDK 的公开 CRUD 接口。定位、分享、相机、邮件草稿和短信草稿适合后续做成用户主动触发的前台工具，不能设计成静默后台操作。

- **基础助手**：计算器、日期时间、询问用户。
- **资料助手**：基础助手 + 当前会话导入的文本列表、检索、分页读取。
- **研究助手**：资料助手 + 网页读取和联网搜索。缺少域名或所选 API 的搜索 Key 时仍保留勾选，并显示待设置；百度网页问答无需搜索 Key。

日期工具支持当前时间、时区转换、日历加减及时间差。计算器使用受限表达式与 Double，不提供财务精度。`web.fetch` 只读取允许域名中的静态 HTML / 文本；手动 WebView 浏览与可选的百度网页问答分别使用独立入口和会话。

“设置 → 搜索设置”集中管理搜索总开关、默认方式、模型自动搜索服务、各通道开关、独立 Key 和可选网页读取域名。关闭通道不删除其 Key，切换任务工具不会关闭已配置的搜索服务；不自动选择备用通道或重试。模型在本次任务首次联网时确认一次，面板说明首个操作、所选搜索服务、允许的网站和本轮上限；同一次发送的后续网页读取和搜索复用这次许可。下一条消息、任务结束、失败或取消后重新确认，不扩大域名或服务范围，每次执行仍生成独立且绑定参数的授权凭据。

工具失败会显示已确认的工具名称和固定原因，如参数不符、域名受限、授权未完成、HTTP 失败、资料失效或运算错误，并提供对应设置与手动搜索入口。错误页和运行统计可查看、选取或分享诊断；本机 `Application Support/AgentLabDiagnostics/failures.json` 最多保存 20 条、总计不超过 64 KiB，重开 App 后仍可回读，并向系统日志写入固定错误码和计数。不保存问题正文、网址参数、任意底层错误、响应正文或凭据，不自动上传。网络派发后结果未确认时，保留 SDK 的恢复状态和已知失败原因；不自动重发。网页输入及精确域名权限、DeepSeek 查询限制均在请求授权前检查。

聊天工具卡片提供“百度搜索并回答”：明确点击后启用百度公开网页通道并勾选搜索工具，沿用普通任务与会话切换流程，保留草稿和未发送材料。模型调用 `web.search` 时经一次任务确认，在后台临时未登录页面读取公开结果；不弹出或自动导航到 WebView，界面仅显示行内进度与停止按钮。结果以 `BoneWebSearchOutput` 结构化返回标题、来源、摘要和读取时间，交回真实 Conversation，由当前模型整理回答。无需搜索 API Key，模型用量仍按模型账户计；不会开启 Brave/DeepSeek API 或改变回复 Token 上限。手动“百度网页搜索”继续只带入空白搜索框，保留已有搜索草稿，点击搜索才打开网页。

输入框上方持续显示下次任务的搜索通道和缺失 Key 状态。“启用百度搜索”仅准备通道与暂存工具选择，不会发请求。显式勾选联网搜索且尚未配置任何自动通道时，准备无需搜索 Key 的百度通道；已配置的 API 选择和开关保持不变。未开启自动搜索而误用静态正文工具时，错误卡片可直接“百度搜索并回答原问题”，会保留另一条草稿，沿用新会话确认与任务内联网确认；两个独立草稿位置均占满时阻止覆盖。百度搜索及网页读取不依赖 DeepSeek 搜索 Key；模型回答仍需所选模型自己的连接凭据。

请求边界用于限制工具循环和累计资源消耗：每轮最多 6 次主推理、8 次工具调用和 120 秒，等待联网确认或问答也占用本轮时间。模型输出截断、上下文整理失败和推理步数超限分别显示对应原因，不再全部使用“请求限制”。SDK 若只提供合并后的预算错误，则保留预算错误码和实际观察到的计数，不猜测具体触发项。单次回复 Token 上限来自模型设置，截断不等于推理次数已耗尽。

输出截断时，错误卡片展示模型最大输出与本次实际配置，按精确模型容量提供下次回复预算选项；不再统一封顶 8192。选择仅保存配置，不自动重发。可见的截断文字单独标为“未完成内容（未提交）”，不作为成功回答或 SDK 已提交历史。SDK 仍拒绝不完整响应与工具参数。附件任务指导模型先简要回答、按需分页，避免默认逐字复述整份文件。

## 模型容量与自动压缩

模型设置的“回复与上下文”分别显示模型声明、当前请求输出预算和本机上下文窗口。精确匹配已配置服务商、接口与模型 ID 才采用容量事实；自定义网关和未知型号不按名称猜容量。SDK 目录声明保留来源链接；Demo 额外核验的官方事实只绑定 `MiniMax / https://api.minimaxi.com/anthropic / MiniMax-M3.1-Flash`，未修改核心 SDK 目录。

2026-11-18 核验：[MiniMax Anthropic 接入说明](https://platform.minimaxi.com/docs/api-reference/text-anthropic-api)列出该型号上下文 1,000,000 Token、强制思考且思考 Token 计入生成预算；[消息生成参数](https://platform.minimaxi.com/docs/api-reference/text-chat-anthropic)声明 `max_tokens` 推荐 131,072、上限 524,288。“填入模型建议”只改变设置草稿，“采用模型建议”只保存明确显示的输出和窗口，不发送请求，也不启用摘要。旧配置的 1024 / 32768 / 摘要关闭保持不变。

输出预算在 128～1,000,000 的 App 可配置范围内再受已知模型上限约束；未知型号的 App 范围不是模型支持声明。有效上下文取本机窗口与模型已知容量的更小者，预留本次输出、128 Token 协议额度与 2%（至少 16 Token）安全余量；图片还受 SDK 视觉余量约束。显示与执行使用同一预留规则。主回复和摘要各自携带输出预算，共用偏好取两者较大值，避免 SDK 默认 4096 或主回复小额度把已选预算意外收紧。

“自动上下文压缩”默认只裁剪旧完整用户轮次。达到可用输入预算的 85% 才触发，目标 65%，保留当前用户问题；低于阈值不会发摘要。“使用模型摘要”需明确启用，会产生额外模型请求；新启用时普通型号填入 2048、思考与正文共用预算的型号填入 8192，用户仍可修改。旧摘要配置未指定预算时保留 512。每次 Run 最多一次摘要，与主推理共用时间、次数及累计字节预算。

“压缩当前任务的旧工具记录”需自动压缩、模型摘要与本开关同时开启。仅移除当前任务已完成的旧工具调用/结果对，保留最近两组、当前问题及系统说明；SDK 重建并校验历史。摘要/裁剪是有损操作，完整但不可用的摘要可按 SDK 策略回退裁剪；网络失败、未知结果和取消不会盲目重试。受保护部分仍装不下时显示具体上下文失败原因。

运行统计显示本轮已提交压缩次数、移除旧轮次/工具交换、估算减少 Token、是否摘要及裁剪回退，未触发时明确无记录。Token 估算不是厂商 Tokenizer，压缩不提高输出上限或自动续写。更大预算仍受独立执行边界约束：默认累计输入 512 KiB、输出 256 KiB；显式增大窗口/输出后按配置有界扩展（输入与输出最多各 16 MiB，流式最多 32 MiB），任务仍最多 120 秒。模型最大能力不是完成或费用保证。

`web.fetch` 在授权和 HTTP 请求前将已知百度、必应搜索结果页引导至专用搜索方式，避免用静态正文工具猜测实时数据。普通获准静态页面仍按原域名策略读取，跳转拒绝与响应损坏分别记录，不自动跟随跳转或扩大允许域名。

`WeatherSearchSimulationTests` 用“今天桐乡温度”覆盖 MiniMax 兼容流式 Provider、日期工具、独立 DeepSeek Search API、结果回传及来源，验证正常模拟路径为 3 次推理、2 次工具调用、1 次联网确认。另覆盖当前仅网页读取的七工具配置、302 跳转、无效 UTF-8 和搜索结果页路由。全部使用假 Key 与明确标注的离线数据；测试中的温度不是实际天气，也不能替代真实模型和账号的在线验收。

新增百度网页问答模拟覆盖无搜索 Key、两次搜索只确认一次、原查询和来源进入下一次 MiniMax 兼容模型请求、拒绝授权不启动浏览器、取消不提交或重放、验证/超时/导航变化保留固定原因。`BrowserSearchSnapshotTests` 校验冻结查询、第一页、精确来源、追踪参数剔除、UTF-8 上限和会话绑定。

`SearchEntryRecoveryTests` 覆盖无自动服务时准备百度、保留已有 API 选择、显式百度操作不改其他通道和手动偏好，以及重试原问题时保留下一条草稿、两个草稿均占用时拒绝覆盖。

## 搜索模块

- **网页搜索**：搜索页直接提供必应、百度引擎选择；无需搜索 API Key，点击搜索才在 WKWebView 打开对应查询。聊天页“百度网页搜索”直接带入百度模式与当前问题。长按选择一小段文字，再点“使用选中的文字”，核对来源后加入草稿。不会自动抓取搜索页、读取整页、提交表单或绕过登录与验证。默认使用临时 WebKit 会话，可显式选择保留网页登录状态。
- **百度网页问答**：默认关闭；聊天页“百度搜索并回答”可明确选择，或在搜索设置启用。后台创建 `.nonPersistent()` 桌面 WebKit 渲染器，使用匹配的桌面 Safari 请求标识和 1024 × 768 有界布局尺寸，不加入视图层级或窗口，不复用手动浏览登录态。加载由读取任务自行启动，不依赖页面是否出现、列表滚动或弹层，界面只显示状态和结构化结果。只允许固定百度 HTTPS 搜索路径、同一查询和第 0 页；同查询的 HTTP 降级请求会被取消，已有 HTTPS 结果保留，必要时最多重建一次规范 HTTPS 请求，最终仍只接受 HTTPS 页面。仅提取已渲染的 `#content_left` / `#results` 区域，排除表单、输入、可编辑区、隐藏元素和脚本，不读取 Cookies。提取最多 8 KiB，工具摘要最多 2 KiB，附规范来源链接、读取时间和不可信数据标记。最长 28 秒；登录、安全验证、查询变化、其他导航、无结果、超时或取消即结束，不自动打开浏览器或回退至收费 API。结果卡片可核对实际交给模型的摘要。
- **Brave Search**：正式 JSON API；需要独立 Brave Search Key。搜索页与模型 `web.search` 共用适配器，支持 SDK 有界分页与来源结果。
- **DeepSeek Search**：按[官方独立 Search API](https://api-docs.deepseek.com/api/search/)接入 `POST https://api.deepseek.com/v1/tools/search`，使用单独配置的 DeepSeek Key，不要求聊天使用 DeepSeek 模型。每次查询最多 128 个 Unicode 字符，只接受第 0 页，本 Demo 请求 `need_content=false`，仅采用标题、链接和短摘要。服务端原生聊天搜索工具未在本次接入。

默认方式控制搜索页；“模型自动搜索”明确选择百度网页问答、Brave 或 DeepSeek，只有任务勾选搜索工具后才注册。搜索页发起的请求只将结果保留在此页；选取结果先追加到现有任务草稿，点击运行才发送给当前模型。聊天页自动问答经任务确认后直接将工具结果交给模型。草稿总上限 16 KiB，单次手动选取最多 8 KiB，不自动上传 Cookies 或表单内容。

两个搜索 Key 分别保存在本设备 Keychain，和模型 Key 分离，不进入偏好或模型请求。搜索 API 接收阶段最多 1 MiB、结果最多 32 KiB，拒绝重定向和自动重试；错误信息不包含响应原文或凭据。API 的额度、计费与网站授权范围以各服务官方条款为准；浏览网页不代表取得自动采集或再分发许可。

“询问用户”支持单选、多选和文本。回答面板等待真实操作，最多 90 秒；取消或超时结束本次请求。回答会回传当前模型，但不授予任何其他工具权限。Demo 使用任务内联网许可及逐次绑定的执行授权和回执，不提供跨进程工具重放或 Workflow 恢复。

## 真实模型测试

在实验室选择任务类型后，点击“开始真实测试”才会向当前服务商发请求：

- **模型回复**：检查是否严格回复“连接正常”；普通文字回复不自动算通过。
- **工具计算**：使用同一工具选择，示例会勾选计算器。检查实际计算器输出为 391，且模型回答包含正确结果；只写出数字、未调用工具不能通过。
- **连续对话**：第一轮发送新的随机编号，第二轮通过同一 Conversation 提问，检查实际两轮请求和编号回忆结果。
- **助手说明**：使用共享说明和当前任务。填写检查词时仅做文字包含检查；未填条件时标记“待你检查”，不声称已验证语义遵循。

每次运行冻结模型、说明、工具和输入快照；结果展示实际回答、调用次数、耗时、服务商上报用量及实际请求，可主动分享。结果仅保留本次进程内，不自动保存或重放。旧的七个脚本场景继续用于自动回归，不代表服务商在线验收。

## 更多能力

- **结构化输出与验收**：将最多 16 KiB 原文交给当前模型，实际请求 JSON Schema 并执行 SDK 本地校验。自动修正默认为 0，可明确选择 1～2 次；只修正完整候选结果的格式/字段错误，认证、网络、取消、截断等失败不重试。
- **Workflow 执行与检查点**：使用当前模型、冻结设置、真实 `runWorkflowStep` 和 Run / Step / CAS 检查点。最多六次模型与八次工具调用，只注册可选只读计算器。未知派发禁止重跑，确认终态的 Step 可显式安全收口；进程内实验不提供跨进程 Workflow 恢复。
- **文本预览与分页回读**：无需 Key，本机预览和真实 `resource.readText` 分页。展示字节数、offset 和 nextOffset，可核对 Unicode 页边界。
- **本地模型与设备检查**：接入 `BoneAgentLocalModels` 的目录校验、设备环境、托管库存、显式下载/取消、完整性检查和删除。SDK 当前未附带下载清单，需导入可信来源的 SDK 目录 JSON。仅点击下载才访问来源，测试禁网；仓库未注册可执行 llama 运行时，文件存在不等于可以本地推理。

默认只在进程内保留对话。启用本机保存后，聊天正文、SDK 工具历史及导入材料写入 App 私有目录，使用 iOS 完整文件保护并排除备份，不包含 Key。发送前先保存请求进行中标记；中断后只恢复此前完成的历史并要求新对话，不会重发。模型/连接/工具配置不同的记录拒绝载入。开始新对话或关闭保存会清理存档；恢复前的时延与用量不持久化。

Key 使用本机 Keychain（仅本设备、解锁时可用），并绑定协议和接口地址；其他设置保存在 App 偏好中。切换接口时不把旧 Key 自动带到新服务器，可在设置删除该接口的 Key。

点击发送、开始真实测试、JSON 检查或任务执行后，内容会发送至配置的服务，费用由服务商计算；连续对话测试包含两轮请求，工具任务可能多次请求模型。保存设置本身不联网。自动回归的测试数据不能证明某个账号或真实模型的在线质量。

## 测试范围

真实对话通过 `BoneAgentProviderFactory` 和 `BoneAgentConversation` 发送，保留成功轮次和工具结果。流式适配真实 Provider 事件，只有完整终态才提交回复；不支持流式时可在设置手动关闭，不自动回退重发。输入、系统指令各限制 16 KiB；每轮最多六次主推理、八次工具调用、120 秒 SDK 操作边界，并限制累计字节。可选摘要额外最多一次，与 SDK 共享预算。上下文 Host 上限与 SDK 已知模型限制取交集，在 85% 触发、以 65% 为整理目标；不代表官方容量或账单。

## 大文本文件（2026-11-18）

聊天加号与实验室工具工作台的文件选择入口共用 `LiveChatModel.importText`：普通 UTF-8 文件最多 100 MiB，单会话总共最多 4 份。文件导入在资源 actor 上执行，security-scoped URL 的访问期覆盖整个导入。小于等于 512 KiB 的文件继续保存为旧 `PrivateState` v1 小附件（合计最多 2 MiB）；更大文件由 `BoneDiskTextResource` 持有匿名私有临时快照，模型只接收最多 1 KiB 的首段预览。来源文件之后变化不改变快照，移除/清空或进程退出会释放快照。实验室粘贴编辑器仍限制 512 KiB。

大附件仅在“本机保存已完成会话”关闭时可用。开启时导入明确拒绝；导入后重新开启保存也在偏好/凭据写入前拒绝，保留当前草稿和资源。发送、会话组装、SDK 会话导出和附件导出均复核保存边界；附件 store 含任意大附件时整体拒绝导出，不会过滤它后写出残缺会话。主动关闭保存、变更配置和重置会话继续执行原有存档清理策略；只有被拒绝的导入或开启保存操作不能碰旧存档。只有小附件的正常会话继续使用原存档和恢复流程。

每次 list/search/read 都检查当前资源和会话授权。移除资源或撤销授权后，已经注册的工具也无法继续读取。搜索对小文本保留既有匹配语义，对磁盘文本使用区分大小写的原始 UTF-8 字面匹配；单次磁盘扫描共享 100 MiB 总预算，小文本集合另限 2 MiB。搜索最多 20 条命中、摘要合计最多 32 KiB；没有扫描完或命中被截断时保留 `isTruncated=true`。此时即使没有命中也只能说“已扫描范围内未发现”，不能声称全文不存在。

`resource_read_text` 仍支持旧 `firstRead={resourceID,page:0}`。普通 `nextRead` 使用 Host 按完整 reference 缓存的页起点，每次顺序续读只读取一页；缓存仅含整数，用字典下标原地追加，避免顺序读取时重复复制偏移数组。页码范围扩展至 8192，覆盖 100 MiB 的 UTF-8 边界分页。

搜索 `snippet` 可直接引用；扩读使用 `{resourceID: hit.resource.reference.id, offset: hit.matchOffset}` 或 `snippetOffset`，无需从头扫描。offset 模式忽略 page，返回的 `nextRead` 继续携带实际 `nextOffset`，不推算命中对应的文件页码；该模式的输出 page 固定为 0，实际位置以 offset 为准。禁止手算落在 UTF-8 scalar 内部的偏移，服务端仍做验证。

回归覆盖真实 100 MiB 文件导入/尾部读取、超限拒绝、来源修改后快照稳定、保存冲突及小文件旧存档恢复、部分搜索、尾部命中直接扩读、每次续页仅一次实际读取、撤销与移除后的工具行为。`ResourcePageTests` 同时验证 offset 模式连续扩读、页码边界与 nextRead schema。完整 Demo 测试还覆盖既有假模型 firstRead/nextRead 和失败恢复。

Debug 离线设置诊断使用 `--live-chat-ui-test --file-recovery-ui-test --run-file-recovery-diagnostic --disk-resource-ui-test`。`FileRecoveryUITests.testDiskResourceImportBlocksPersistenceAndPreservesArchive` 使用自建 512 KiB+1 文件，检查保存开启时拒绝导入、关闭后可导入、再次开启被拒绝、被拒操作保留存档、主动关闭保存与重置清理存档、待发附件保留和实际尾字节读取；不访问用户文件或真实模型账户。

运行这条 UI 测试请保留 Xcode 默认的模拟器签名。测试会把假 Key 写入隔离的 Keychain；设置 `CODE_SIGNING_ALLOWED=NO` 会使它在建立测试配置时失败，尚未执行附件断言。
